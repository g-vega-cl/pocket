# User Stories

## Fix a Bug

1. Paste repo URL
2. Enter task description
3. Clone → Create Branch
4. Chat: "Fix the NPE in user_service.py"
5. Agent reads, fixes, commits, pushes, creates PR

## Add a Feature

1. Paste repo URL
2. Enter task description
3. Clone → Create Branch
4. Chat with detailed request
5. Agent implements, creates PR

## Resume Session

1. Enter session ID
2. Click Resume
3. Continue where left off
