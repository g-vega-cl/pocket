# User Stories

## Fix a Bug

1. Paste repo URL
2. Enter task description
3. Clone → Create Branch (pushed to origin automatically)
4. Chat: "Fix the NPE in user_service.py"
5. Agent reads, fixes. Changes are auto-committed, pushed, and PR created
6. Continue chatting or start a new session

## Add a Feature

1. Paste repo URL
2. Enter task description
3. Clone → Create Branch (pushed to origin automatically)
4. Chat with detailed request
5. Agent implements. Changes are auto-committed, pushed, and PR created
6. Continue chatting or start a new session

## Resume Session

1. Enter session ID
2. Click Resume
3. Continue where left off
